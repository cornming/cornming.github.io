# 使用統計的後端（Google Apps Script）

晚安瑜伽、SlowJog 網頁版在使用者「完成一次」時，會把一筆匿名紀錄送到這裡；[/stats/](../stats/index.html) 再從同一個網址讀回統計。

## 收什麼、不收什麼

每一筆只有五個欄位：時間、作品、課程代號、完成當下的小時（使用者手機的當地時間）、這個瀏覽器第幾次完成的分級（1、2、3、4+）。沒有帳號、沒有裝置編號、沒有 IP。

「第幾次」的次數存在使用者自己手機的瀏覽器裡，送出去的只有分級。每個瀏覽器的第 1 次只會出現一次，所以第 1 次的筆數約等於不同的手機數，統計頁用「第 2 次 ÷ 第 1 次」算回訪率。換手機、清除瀏覽資料會被當成新的人，回訪率通常會偏低。

「完成」的定義：

- 晚安瑜伽：整組課程走完，而且實際練習時間至少是課程總長的一半（連按「下一個」跳到最後不算）。單獨的呼吸練習、中途離開都不算。
- SlowJog 網頁版：達成當次目標（課表走完，或時間／距離目標到了）並按「儲存並結束」。選「放棄這次紀錄」、中途結束都不算。

## 檔案

- [`Code.gs`](Code.gs)：貼進試算表的 Apps Script。只接受已知的作品與課程代號、小時 0 到 23，全站每分鐘最多收 30 筆。
- 資料存在一份 Google 試算表的第一個分頁，欄位順序：時間、作品、課程、小時、第幾次。第 5 欄的表頭在第一次收到新資料時由程式自動補上；舊資料沒有這一欄，統計時算在「未知」。
- [`Code.test.js`](Code.test.js)：用假的 Google 服務在本機驗證 `Code.gs` 的邏輯，`node apps-script/Code.test.js` 就能跑。它不能代替部署後在真正的 Google 環境試一次。

## 重新部署

1. 開試算表，選「擴充功能 → Apps Script」，把 `Code.gs` 整份貼進去存檔。
2. 「部署 → 新增部署作業 → 網頁應用程式」，執行身分選「我」，誰可以存取選「所有人」。
3. 複製 `/exec` 結尾的網址，更新三個地方：
   - [`_config.yml`](../_config.yml) 的 `stats_endpoint`
   - 晚安瑜伽 `src/web.rs` 的 `STATS_URL`
   - SlowJog 網頁版 `web/src/web.rs` 的 `STATS_URL`

之後如果只是修改 `Code.gs`，要用「部署 → 管理部署作業 → 編輯 → 版本選新版本」，網址不會變；單純存檔不會讓線上版更新。

## 限制

收集網址是公開的、沒有登入驗證，所以數字只是約略值，不能當成嚴謹的使用人數。
